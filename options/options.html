About Auto Fill Test Helper

✨ Features

  • 4 Built-in Profiles - QA Standard, Edge Case, Minimal, International
  • Locale Support - Customize city, state, postal code, phone format for different countries
  • Advanced DOM Handling- Shadow DOM, iframes, custom widgets
  • Smart Field Matching- Intelligent context-aware value selection
  • Keyboard Shortcuts - Fill forms with Alt+Shift+F
  • Console API- Programmatically trigger fills from browser console
  • Configuration Management - Export/import your settings
  • Multi-Step Forms- Optional auto-advance through wizard pages

🛠️ Usage

  1. Load the extension in your browser
  2. Open a page with a form to test
  3. Click the extension icon and press "Fill form"
  4. Or press Alt+Shift+F for quick fills
  5. Use the console API: window.autoFillTest({ mode: 'overwrite' })

🐛 Troubleshooting

  • Extension doesn't fill - Refresh the target page
  • File:// URLs not working - Enable "Allow access to file URLs" in extensions settings
  • Brownser built-in pages can't be filled - NameError
  • Custom pages not filling - Check if the extension is loaded for that origin
